# MERN Task Manager

A full-stack task management application built using MongoDB, Express.js, React.js, and Node.js.

## Features

- User Authentication
- Create Tasks
- Update Tasks
- Delete Tasks
- Responsive UI
- JWT Authentication

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- JWT

## Live Demo

https://mern-task-manager-dusky.vercel.app

## Installation

git clone <repo-url>

cd frontend
npm install

cd backend
npm install

npm start
